Orientation

Two independent connections

Move exposes two unrelated interfaces. Pick the one the task needs; switching means leaving the other.

USB‑C Control Live

Move becomes a control surface for Live 12: pads, knobs, transport, device control. Uses the factory Move MIDI Remote Script that ships inside the Live app — nothing to install.

Use it for: playing and recording into a Live set from the hardware.

Wi‑Fi Move Manager

Move runs a web app and HTTP API at http://move.local (ports 80 and 22). Browse, download, upload, rename and delete Sets, Samples and Recordings; ask Move to render a file to audio.

Use it for: getting Sets and recordings onto this machine, and scripting Move's storage.

Mutually exclusive

Control Live only works over USB, never Wi‑Fi. And while Control Live is active the file API refuses uploads. Put Move back in Standalone Mode (its normal state) before pairing or syncing.

Mode A

Control Live over USB

  1. On Move, hold Shift and press Step 2 to open the Setup menu.
  2. Turn the wheel to Control Live, press the wheel to confirm.
  3. Connect USB‑C and open Live. The Move control surface auto‑configures.
  4. Verify under Settings → Link / Tempo / MIDI: Control Surface = Move, input and output = Move.

Requirements

Live ≥ 12.1 (we run 12.3.5). Script path, for reference only:

/Volumes/Bisonte/Applications/Ableton Live 12 Suite.app/
  Contents/App-Resources/MIDI Remote Scripts/Move/

It is one of 144 factory scripts. Don't copy it into the User Library; Live loads it from the app bundle.

Mode B

Move Manager over Wi‑Fi

Move and the Mac must be on the same network. Open http://move.local in a browser for the web UI, or use the API directly.

Pairing (one‑time per 30 days)

  1. Client sends POST /api/v1/challenge with Accept: application/json.
  2. Move shows a 6‑digit code on its display.
  3. Client sends POST /api/v1/challenge-response with {"secret":"123456"}.
  4. Response sets cookie Ableton-Challenge-Response-Token, Max‑Age 30 days. Send it on every later call.

Move must be in Standalone Mode to pair. Wrong code → 401. Too many tries → 429 with Retry-After.

Day‑to‑day tool

move‑sync.py

Stdlib‑only Python 3.10 script, already paired. Lives next to the pulled Sets. It re‑pairs itself when the cookie expires: Move shows the code, you type it in.

# working directory
cd ~/Music/Ableton/Move\ Sets

python3 move-sync.py sets              # download every Set as <Name>.ablbundle
python3 move-sync.py list              # browse Move's storage tree
python3 move-sync.py pull Recordings   # mirror a raw bucket (Samples, Recordings…)

# then: double-click any .ablbundle to open it in Live 12

Reference

HTTP API

Reverse‑engineered from Move Manager's JS bundle. Everything under /api/v1/ needs the session cookie except /language.

MethodPathDoes
POST/api/v1/challengeStart pairing; Move displays code. Needs Accept: application/json or you get a bare 400.
POST/api/v1/challenge-responseBody {"secret":"<code>"} → Set-Cookie: Ableton-Challenge-Response-Token
GET/api/v1/files/Top‑level buckets
GET/api/v1/files/<path>List a directory, or download a file
POST/api/v1/files/<path>Create directory, or multipart upload (?overwrite=true)
PATCH/api/v1/files/<p>/<name>Rename / move: body {"path":"new/full/path"}
DELETE/api/v1/files/<path>Delete
GET/api/v1/convert/<path>.wavMove renders the file to audio and returns the WAV
OPTIONS/api/v1/files/<path>Capabilities plus disk‑usage headers
GET/api/v1/is-move-running · system/version · cloud-auth/* · ssh · syslog/zip · updateHousekeeping endpoints
 
# minimal curl session
curl -s -X POST -H "Accept: application/json" http://move.local/api/v1/challenge
# …read the 6-digit code off Move's display…
curl -s -c jar.txt -X POST -H "Content-Type: application/json" \
     -d '{"secret":"123456"}' http://move.local/api/v1/challenge-response
curl -s -b jar.txt http://move.local/api/v1/files/Sets/ | python3 -m json.tool
Hard‑won

Quirks

Paths come pre‑encoded

path values in responses are already URL‑encoded (Alice%20Ivy). Reuse them verbatim in URLs; unquote only for display. Encoding them again gives a 404.

Error decoder

401 {"error":"Unset credentials"}no / expired cookie
401 on challenge‑responsewrong pairing code
429 + Retry-Afterrate‑limited pairing
bare 400 on challengemissing Accept header
upload refusedMove is in Control Live mode

Before you save as .als

Duplicate the Set on Move first if you want to keep iterating on the hardware. Once it's a Live project it stays a Live project.

Alternative route: Move Manager → Settings → enable Cloud, sign in to Ableton Cloud in Live, Sets appear under Places → Cloud. Works, but LAN sync is faster and doesn't burn hotspot data.
